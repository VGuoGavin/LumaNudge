# 兼容性与故障排查

## 支持范围

| 场景 | 当前行为 |
| --- | --- |
| Windows 10/11 x64 笔记本，内屏 WMI 亮度可读 | 内屏为来源，DDC/CI 外屏为目标 |
| Windows 10/11 ARM64 笔记本 | 32 位 x86 通用启动器选择 ARM64 原生程序；仍需 ARM64 真机验证 |
| 台式机或内屏 WMI 亮度不可读 | 主 DDC/CI 显示器为来源，其他可读外屏为目标 |
| 多台外屏 | 各外屏先读取自己的当前亮度，再分别应用相同变化量 |
| 显示器不支持 DDC/CI，或连接链路未透传 | 亮度不可读，跳过该显示器 |
| 外屏拔掉后重新接入 | 快速恢复监听；等待来源亮度下一次变化才调整外屏 |

## 外屏没有变化

1. 在程序菜单中选 `5`，或运行 `--list`。确认目标外屏显示亮度百分比，而不是“DDC/CI 亮度不可读”。
2. 检查显示器 OSD 中的 DDC/CI 设置。若使用转接器、扩展坞或 KVM，可暂时直连电脑测试。
3. 确认系统识别的是扩展显示器，且来源亮度确实发生了变化。首次启动或刚重连时不会立即写入外屏；请随后调整来源亮度 1–2 个百分点。
4. 查看 `--status` 是否显示正在同步；如果暂停，可用 `--start` 恢复。
5. 有些显示器虽然报告支持 DDC/CI，但读取或写入可能不稳定。可换接口、线缆或显示器设置再次验证。

## 亮度值的含义

外屏百分比由其 DDC/CI 最小值、当前值和最大值换算得到。不同品牌的背光曲线不同，因此相同百分比不一定具有相同的实际亮度或视觉效果。HDR、显卡软件调光和显示器 OSD 的其他图像处理也可能改变观感。

## 当前限制

- 所有可读的非来源外屏都会参与同步；尚未支持指定型号或按序列号持久绑定。
- 没有 DDC/CI 的外屏无法通过此程序读写自身的亮度设置。
- 目标读取失败时，本次变化会跳过该目标；来源亮度不再次变化就不会补发。
- 连接检测依赖 Windows 显示器/设备变化消息以及定时兜底检查。显示器初始化所需时间取决于设备和连接链路。
- 拔掉所有目标后会保留休眠监听进程，以便快速恢复。
- 当前发布文件未签名；部分 Windows 安全界面可能提示确认。
